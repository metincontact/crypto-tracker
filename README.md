# Crypto Tracker

A real-time cryptocurrency tracker built with React, TypeScript, and Tailwind CSS.

## Features

- Top 50 cryptocurrencies by market cap
- Real-time prices and 24h change
- Search coins by name or symbol
- Coin detail page with 7-day price chart
- Add/remove favorites with localStorage persistence
- Fully responsive dark theme

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- React Router
- Recharts
- CoinGecko API
- Vite

## Live Demo

[crypto-tracker-matin.vercel.app](https://crypto-tracker-matin.vercel.app)

## Getting Started

```bash
cp .env.example .env
# Add your CoinGecko API key to .env
npm install
npm run dev
```
